# 🦅 AIDroneWars 🛡️✨🚀💣

**AIDroneWars** is a fully autonomous 3D tactical drone combat simulation built with **Blazor Server**, **Babylon.js**, and **Ollama (AI)**. 

The simulation features a high-performance drone that patrols a map, identifies "Points of Interest" (POIs) using a proximity radar, and consults an **AI Intelligence Officer** for engagement orders. 

---

### 🏮 Key Features:
- **🦅 Autonomous Pilot:** A persistent waypoint-based flight engine.
- **🧠 Agentic AI Brain:** Tactical evaluation via **Ollama (Qwen3:8b)** for Friend-or-Foe classification.
- **💥 Kinetic Engagement:** Particle-based explosions and target neutralizing logic.
- **📊 Tactical Log:** A "Full Flight Recorder" UI with raw sensor and intelligence stream toggles.
- **🚀 Endless Sortie:** Dynamic POI respawning for continuous combat testing.

### 🏗️ Technical Stack:
- **Frontend:** Babylon.js (3D WebGL Engine) + Blazor (Razor Components)
- **Backend:** .NET 9 (C#)
- **AI Integration:** Ollama (API Bridge)
- **Styling:** Tactical Neon HUD (Vanilla CSS)
